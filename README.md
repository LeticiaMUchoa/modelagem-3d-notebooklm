# Aprendendo Modelagem 3D do Básico com o NotebookLM

## Sobre o projeto

Este projeto foi desenvolvido para o desafio da DIO, utilizando o NotebookLM como ferramenta de aprendizagem ativa.

O objetivo é iniciar os estudos em Modelagem 3D a partir dos conceitos básicos e avançar gradualmente para técnicas de modelagem, ferramentas, formatos de arquivos e preparação de modelos para impressão 3D.

Durante o projeto, foram utilizadas diferentes fontes de estudo e perguntas elaboradas para orientar a pesquisa, permitindo organizar o conhecimento e identificar os principais conceitos aprendidos.

# Cicatrizes e Troubleshooting

# Cicatrizes e Troubleshooting

Durante a realização do projeto, utilizei diferentes recursos disponíveis no NotebookLM para auxiliar no processo de aprendizagem sobre Modelagem 3D.

Uma das primeiras dificuldades que percebi foi que perguntas muito simples geravam respostas mais gerais. Para conseguir informações mais específicas, comecei a elaborar perguntas com mais contexto, indicando o assunto que queria estudar, meu nível de conhecimento e o tipo de resposta que esperava receber.

Também explorei diferentes formas de apresentação do conteúdo disponíveis no NotebookLM. Além das respostas às perguntas, utilizei o recurso de geração de **resumo em áudio**. O NotebookLM produziu um áudio com um resumo do conteúdo estudado, porém o primeiro resultado tinha aproximadamente **1 minuto**, apresentando apenas uma visão geral do material. Isso mostrou que o recurso pode ser útil para uma revisão rápida, mas não substitui uma análise mais detalhada das fontes.

Outro recurso utilizado foi a geração de um **documento com informações organizadas a partir das fontes**. Esse recurso foi útil para estruturar o conteúdo estudado, porém encontrei uma limitação durante o processo: o documento não podia ser exportado diretamente para PDF da forma que eu precisava.

Para solucionar esse problema, utilizei o **Google Docs como etapa intermediária**, copiando o conteúdo gerado pelo NotebookLM para o editor e realizando posteriormente a conversão para PDF.

Essas situações fizeram parte do processo de experimentação com a ferramenta e ajudaram a compreender melhor seus recursos e limitações.

Para melhorar a qualidade das respostas, passei a adicionar aos prompts:

* Contexto sobre o assunto;
* Objetivo da pergunta;
* Nível de conhecimento;
* Formato esperado para a resposta;
* Exemplos práticos;
* Orientação para utilizar as fontes fornecidas.

Também foi necessário analisar as respostas geradas e identificar quais assuntos precisavam de maior aprofundamento.

Essa experiência mostrou que a qualidade das respostas depende também da forma como a pergunta é elaborada. Além disso, as respostas da Inteligência Artificial não devem ser aceitas automaticamente, sendo importante compará-las com as fontes utilizadas e analisar se o conteúdo realmente responde ao objetivo do estudo.

Dessa forma, o troubleshooting não foi apenas uma tentativa de solucionar problemas, mas também uma etapa importante para entender como utilizar melhor o NotebookLM como ferramenta de aprendizagem.

# Glossário

**Modelagem 3D:** processo de criação de objetos tridimensionais utilizando ferramentas digitais.

**Vértice:** ponto utilizado para construir a geometria de um modelo.

**Aresta:** conexão entre dois vértices.

**Face:** superfície formada por arestas.

**Malha:** estrutura formada por vértices, arestas e faces.

**Topologia:** organização da geometria de um modelo.

**CAD:** tecnologia utilizada para criação de projetos auxiliados por computador.

**STL:** formato de arquivo muito utilizado para impressão 3D.

**OBJ:** formato utilizado para representar modelos tridimensionais.

**3MF:** formato desenvolvido para aplicações relacionadas à fabricação 3D.

**STEP:** formato utilizado principalmente em projetos CAD.

**Slicer:** software utilizado para preparar um modelo 3D para impressão.

**Fatiamento:** processo de dividir o modelo em camadas e gerar as instruções utilizadas pela impressora.

**Suporte:** estrutura utilizada para sustentar determinadas partes do modelo durante a impressão.

**Tolerância:** margem dimensional considerada para permitir o encaixe adequado entre peças.
